# Security and privacy

DrainGuard is a hackathon prototype. Images are resized and analyzed in the browser, and reports/evidence are persisted in browser storage on the inspection device. The current app does not provide authentication, shared municipal storage, role-based access, or a retention policy.

Please do not upload sensitive personal information or images containing people, faces, license plates, or confidential locations to the public demo.

If you find a security issue in the repository, avoid posting exploitable details publicly. Open a private GitHub security report if enabled for the repository, or contact the repository owner through GitHub.
