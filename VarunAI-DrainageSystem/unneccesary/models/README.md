# Model attribution

`drain-blockage-resnet50-v1.onnx` is a statically quantized derivative of the ResNet-50 classifier weights published with:

Vandaele, Remy (2023), *Trash screen blockage detection using cameras and deep learning: code and dataset*, University of Reading, <https://doi.org/10.17864/1947.000498>.

The source weights are licensed CC BY 4.0. The related research paper is Vandaele, Dance, and Ojha (2024), <https://doi.org/10.2166/hydro.2024.013>.

The JSON file records the runtime contract and frozen audit summary. Full protocol and limitations are in `docs/MODEL_CARD.md` and `docs/EVALUATION.md`.
