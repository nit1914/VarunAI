# Upstream research assets

`classification_network.py` and `crop_coordinates.txt` are reproduced from the University of Reading dataset release for audit reproducibility. The 94 MB `classifier.pth` file is fetched locally and excluded from Git; the derived, quantized browser artifact is stored under `public/models/`.

Source: Vandaele, Remy (2023), *Trash screen blockage detection using cameras and deep learning: code and dataset*, University of Reading, <https://doi.org/10.17864/1947.000498>.
